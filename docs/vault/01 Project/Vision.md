# Vision

**Tagline:** "An AI code reviewer that weighs the evidence before it speaks."

Themis is a GitHub App that automatically reviews pull requests, paired with a reliability layer that measures review quality and blocks changes that make it worse.

**Core promise:** trustworthy judgment.
- High precision
- Low noise
- Every design decision backed by benchmark numbers

See [[Scope]] for what v1 covers, [[Success Metrics]] for how quality is measured, and [[Architecture Overview]] for how it is built.
