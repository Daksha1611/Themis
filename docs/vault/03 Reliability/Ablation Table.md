- Also compares the two precision-filter base models (`microsoft/codebert-base` vs `deberta-v3-small`) as an ablation row.
- Every [[Metrics]] metric per row. Each row is compared with the previous one by exact McNemar on paired cases, and counts only above the run-to-run noise floor (Q63).
