# psycopg

**What it is:** PostgreSQL driver for Python (psycopg 3), used in async mode. Installed with `psycopg-binary`.

**What it does in Themis:** SQLAlchemy's driver for PostgreSQL (`postgresql+psycopg://`).

**Used by:** [[Storage]], [[SQLAlchemy]], [[PostgreSQL]], [[ADR-020 M1 runtime dependencies]]

**Version:** 3.3.6 (installed 2026-09-29).
