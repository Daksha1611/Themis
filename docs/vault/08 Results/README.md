# Results README

This folder holds **real outputs only**: files produced by an actual run in this repo, either an [[Eval Harness]] run or a label report from `evals/benchmark/label_report.py`.

- No placeholder numbers, ever.
- No estimated, projected, or example metrics.
- Every result must say which benchmark split, model, and commit produced it (label reports: split, labeller, and the hashes of the case and label files).

The public results page is generated by `evals/report.py` and deployed to GitHub Pages by GitHub Actions as a build artifact.
