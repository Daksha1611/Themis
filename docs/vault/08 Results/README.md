# Results README

This folder holds **real eval outputs only**: files produced by an actual [[Eval Harness]] run in this repo.

- No placeholder numbers, ever.
- No estimated, projected, or example metrics.
- Every result must say which benchmark split, model, and commit produced it.

The public results page is generated by `evals/report.py` and deployed to GitHub Pages by GitHub Actions as a build artifact.

Empty until the first real eval run. See [[Metrics]] and [[Ablation Table]].
